# Launcher
Launcher for Repentogon

## rgon-cli (TeamHY fork)

This fork adds `rgon-cli`, a headless (no wxWidgets) command line front-end for
the launcher core, used by [Cartridge](https://github.com/TeamHY/cartridge) to
install, update and launch REPENTOGON. See [headless/README.md](headless/README.md).
